01BACKGROUND

왜 개발했나요?

재난 정보는 여러 기관과 서비스에 흩어져 있어 사용자가 현재 위치와 관련된 정보를 빠르게 확인하기 어려웠습니다.

특히 긴급한 상황에서는 많은 정보를 제공하는 것보다, 사용자가 필요한 지역의 정보를 빠르게 이해할 수 있도록 전달하는 것이 중요하다고 판단했습니다. R-Dash는 재난 현황과 대피소 정보를 지도에서 통합적으로 확인할 수 있도록 기획했습니다.

05RESULT & LEARNING

결과와 배운 점

30초 → 5초API 응답시간 약 83% 개선

동일한 조건으로 개선 전후를 비교한 결과, API 응답시간을 약 30초에서 5초로 단축해 약 83% 개선했습니다. 사용자가 보고 있는 지도 영역에 필요한 데이터만 조회하도록 변경하면서 불필요한 데이터 처리와 화면 표시 부담을 줄일 수 있었습니다.

이 경험을 통해 성능 문제를 해결할 때는 기술을 바로 적용하기보다 데이터 조회·전달·표시 과정을 나누어 원인을 확인하는 것이 중요하다는 점을 배웠습니다. 또한 AI는 답을 그대로 사용하는 도구가 아니라 해결 방향을 탐색하는 보조 도구이며, 제안된 방법이 실제 구조에 적합한지 직접 판단하고 구현과 검증까지 수행해야 한다는 점을 익혔습니다.
